Найзрозумілішою командою була git add, вона додає зміни до коммітів. 
Також команда git status дуже зручна команда, яка дозволяє в будь-який момент побачити поточний стан файлів. 
Невеликі труднощі виникли лише через використання Linux-команди ls замість dir у Windows-консолі, але це було швидко замінено. 
Загалом трудношів не були у виконанні команд та лабораторної роботи у цілому.
